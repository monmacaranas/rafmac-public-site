# Public Repository Security Boundary

This repository is intentionally public and contains only RAFMAC marketing website content.

Never commit any of the following here:
- RAFMAC platform or engine source code
- client tenant identifiers or client operational records
- Microsoft Graph discovery snapshots
- users, devices, findings, tickets, reports, or audit records from clients
- access tokens, refresh tokens, client secrets, certificates, private keys, passwords, or connection strings
- private deployment configuration

The RAFMAC operations platform and client integrations belong only in the private platform repository and authenticated Azure services.
